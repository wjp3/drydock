For the person setting it up

Drydock setup checklist

A one-time, twenty-to-thirty-minute sit-down that leaves a non-technical person able to build with Claude Code and Drydock without ever opening a terminal again. Do it in person or by screen share with control (on a Mac: Messages or FaceTime screen sharing, then "Ask to control"; on Windows: Quick Assist). You press the buttons. They type their own passwords.

Before you start

  • They have a paid Claude plan (Pro or above) and can sign in at claude.ai. Without this, Claude Code does not exist for them.
  • You know whether the computer is a Mac or Windows, and they know its password (installing programs asks for it).
  • They have, or will create during the sit-down, a free GitHub account and a free Netlify account. They choose the passwords.
  • 30 minutes, a stable internet connection, and the playbook PDF open somewhere.

The sit-down

1. The Claude desktop app (5 minutes)

  1. Download from claude.com/download, install, open it, and let them sign in.
  2. Click the Code tab once so it finishes its own setup.

2. Run the installer (10 minutes, mostly waiting)

Mac. Open Terminal (press Command and Space, type Terminal, press Enter). Paste this one line and press Enter:

bash <(curl -fsSL https://raw.githubusercontent.com/wjp3/drydock/v0.1.0/install/Install-Drydock.command)

Windows. Open PowerShell as administrator (press the Windows key, type PowerShell, right-click it, Run as administrator). Paste this one line and press Enter:

irm https://raw.githubusercontent.com/wjp3/drydock/v0.1.0/install/Install-Drydock.ps1 | iex

The installer adds, in order, only what is missing: git, Node.js, GitHub's command-line tool, Claude Code's command-line tool, the Drydock plugin, and a Builds folder with a START HERE note. It opens the browser for sign-ins. When the computer asks for its password, they type it. When GitHub opens in the browser, they sign in (or create the account) and click Authorize.

If you were emailed the installer file instead: on a Mac, right-click Install-Drydock.command and choose Open (double-clicking a downloaded script is blocked the first time). On Windows, right-click Install-Drydock.bat and choose Run as administrator; if "Windows protected your PC" appears, click More info, then Run anyway.

3. Netlify (3 minutes)

  1. Create the free account at netlify.com (they choose the password).
  2. Drydock signs the computer in to Netlify the first time it ships, through the browser. Nothing to do now.

4. Prove it works (2 minutes)

  1. In the Claude app, Code tab, open the folder Builds / my-first-build.
  2. Type / in the message box. You should see /drydock:help in the list. Run it.
  3. If it is not there: type /plugin marketplace add wjp3/drydock, then /plugin install drydock@drydock, then try again.

Their first build, together (45 to 90 minutes)

Do this part with them at the keyboard and you beside them. The goal is that they see the whole loop once: a plan, a stop with evidence, saying "next", and a handoff.

  1. /drydock:setup. They answer the four questions. Choose the plan honestly; the light tier is right for Pro.
  2. /drydock:plan. They describe what they want in their own words. Let them answer the interview; resist answering for them. Read the vision back together. The map review will propose changes; they decide.
  3. /drydock:build S0. The skeleton: an empty app at a web address, one passing test, code on GitHub. Watch the stop message arrive. Point at the evidence lines.
  4. /drydock:ship. Preview first, verified by loading it. They say "go live" or not. Show them the preview link on their phone.
  5. Say next and build S1 if time allows. Otherwise /drydock:handoff, close the app, reopen it, and /drydock:wake so they see that nothing was lost.

Leave behind

  • The playbook PDF, with pages 2 and 3 (the quickstart) printed.
  • The START HERE note the installer put in their Builds folder.
  • The three sentences: "Show me the evidence." "Stop and tell me what's blocking." "Handoff."
  • Your phone number, and the agreement that a screenshot of the screen is a fine way to ask for help.

If something goes wrong

SymptomFix
Terminal says "command not found: claude" right after installingClose Terminal and open a new window, then run the installer line again. New programs appear in new windows.
The Mac blocks the installer fileRight-click it, choose Open. Or use the one-line Terminal command instead, which is never blocked.
Windows shows "Windows protected your PC"More info, then Run anyway. Or use the one-line PowerShell command.
No /drydock:help in the slash menuType /plugin marketplace add wjp3/drydock then /plugin install drydock@drydock in the message box. If the app was open during the install, quit and reopen it.
The GitHub sign-in page never openedIn Terminal or PowerShell: gh auth login --web, then paste the code it shows into the browser page it opens.
"Usage limit reached"The plan's allowance for the period is spent. Wait for the reset. Keep the light tier.
It asks for a password in the chatNever type one there. Sign-ins happen in the browser only. Say "no" and close the prompt.
A permission box about pushing or deploying appears and they did not ask for itThat is the owner gate working. Deny it. Nothing happens.
